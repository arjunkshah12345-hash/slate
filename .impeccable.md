## Design Context

### Users
Founders and editors pairing with ChatGPT. They cut a launch on a shared board of stills.

### Brand Personality
Quiet, native, photographic. Three words: **pictures first**.

### Aesthetic Direction
Primary: Shotbase library. Dark field, real stills, one white detail card, blue only on the act.
Also: Cosmos (chrome disappears so images can speak), Linear (one accent, no decoration), Cap (framed still on a dark stage).

Not: SaaS feature grids, Outfit-on-charcoal marketing, CSS blob plates, stuffed inspector.

Type: system UI for chrome. Pictures carry the brand.

### Design Principles
1. The still is the UI. Chrome stays thin.
2. Library is a photo grid. Detail is a white card.
3. Blue means act. Pins mean stop.
4. One light surface on a dark field. Never invert mid-page.
5. Agent is a chip on the picture, not a chatbot column.
